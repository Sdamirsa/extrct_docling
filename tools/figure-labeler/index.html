    How to label

    1. Pick a figure on the left. The timer runs while you work and fills labeler.time_minutes.
    2. Press P and drag a box around each sub-panel (a, b, c… in reading order). For a single chart use “+ whole image”.
    3. On the right set the panel kind, orientation, title, and each axis: name, unit, scale, range and ticks.
    4. Calibrate the value axis: press “pick” beside ref 1 and click a tick label (or the tick mark), then ref 2 on a far-away tick. Categorical axes: fill ticks first, then pick the first and last category.
    5. Add the legend entries as series (name + colour).
    6. Press A and click each mark (bar end, point, line vertex): a row appears with the value in axis units. Shift+click sets err_hi, Alt+click err_lo of the selected row.
    7. Printed numbers win: focus label_printed, click the printed word on the image; the value fills in with confidence 1.
    8. Cannot read a number? Leave the value empty (null). Never guess; lower the confidence when reading by eye.
    9. Once both axes are calibrated, dots show where each row lands: check they sit on the marks. Use the CSV box to paste a table (header row required).
    10. Tick “done”, then Export figure (or Export all at the end). Put the JSON files in labels/ and send the folder back.
