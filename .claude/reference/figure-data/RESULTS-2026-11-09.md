# Figure-to-data minimal test — 5 figures, Gemma 4 26B-A4B q8 (Ollama), 2026-11-09

Setup: `tests/data/figure_data/testset-5.json`, truth in `tests/data/figure_data/truth/`
(5 figures, 35 panels, 650 values: 96 printed, 554 measured from pixels or
vector geometry by clean-memory labelling agents; validated with
`tools/figure-labeler/validate.py`). Engine: `docling/engines/figure_data/`
v1, `amir-figdata run --testset … --mode measured|simple --model gemma4:26b-a4b-it-q8_0`.
GPU: NVIDIA GB10, 28.1 GB resident for the model, ~35 output tokens/s.
Raw outputs (per-figure JSON, overlays, timing): session scratch `run26b/`.

### What worked
- **Panel splitting from gutters: 35/35 panels, all kinds right but one** (F4
  panel 1 called a bar chart). No model needed.
- **Vector route: exact and free.** F5's 15 slices from wedge angles plus
  printed labels, 0.02 s.
- **Printed labels: exact** wherever paired (F1's 24 "Correct" values, F3's
  panel-b percentages). Axis calibration from tick words worked on every
  raster panel with a numeric axis (F2 25–91, F3 0.2–0.8).
- **Model's own readings on line charts are usable**: F2 45/52 within 5 % of
  the axis range; F4 values eyeballed against truth are close (0.35 vs 0.376,
  0.55 vs 0.561, 0.85 vs 0.827, 0.95 vs 0.953) even though the scorer
  matched none (see below).

### What failed, with cause
1. **Pointing.** Gemma 4 26B-A4B returns mark positions that are not on the
   marks (overlay: scattered, often a constant row). Converting them through
   the axis map gives 12 % error; F3 bar tops came out 0.05–0.10 low. The
   small E4B model did the same. Do not derive numbers from this model's
   pointing.
2. **Stacked bars: missing series.** F1 returned 52 rows (Correct + Incorrect
   for 24 bars) and almost none of the four middle segments; the Incorrect
   values were ~9 points high because the segment was measured from a wrong
   start. A labelling agent measured all 144 segments exactly from colour runs
   along each bar in minutes: that deterministic method belongs in the engine.
3. **Legend not propagated to panels.** Per-panel crops lose the shared
   legend: F3 panel b got "Series 1–4" instead of 0/1/2/3, F4 invented series
   names from other text. The figure-level legend (swatch colour → name) must
   be read once and passed to every panel, and series matched by colour.
4. **x values null on log/categorical axes.** F4's model rows had `x: null`
   so nothing matched (category F1 0.02). Assign x by order along the fitted x
   ticks when the model omits it; give the model the tick list explicitly.
5. **Time.** 21.7 GPU-minutes for 35 panels ≈ 37 s per panel; F4 alone 11
   min. Output tokens dominate (20.7 k for F4); a structure-only prompt (no
   per-point coordinates) would cut tokens by more than half.

## Cost per paper (projection)
The 14-paper batch has a median of 3 chart-like figures per paper (range 1–9)
and these 5 figures averaged 7 panels each; a typical paper is nearer 2–3
panels per figure. At 37 s/panel measured ≈ 4–6 min per paper on top of the
~3 min conversion; the vector share (≈ 25 % of chart figures) costs nothing.
With a structure-only prompt and deterministic geometry the model time should
drop to ~10–15 s/panel.

## Decisions for the next iteration
- Keep: panel splitter, vector reader, printed-label pairing, axis
  calibration, verifier, schema, scorer, labelling kit.
- Change the division of labour: VLM reads **structure only** (kind, axes
  names/scale, legend swatches → series, category labels, which series each
  bar/line is) plus its own value estimate as a fallback; **numbers come from
  deterministic colour geometry** on the native bitmap: bar tops and stacked
  segment runs per legend colour, line tracing at tick columns, error-bar caps.
  This is exactly how the labelling agents reached ±0.2 % by hand.
- Propagate figure-level legend to panels; assign x by tick order when the
  model returns null; add the model's own number as the fallback source with
  confidence 0.5 (it was 3 % off on lines).
- Then rerun the same 5 figures (≤ 30 GPU-min) before the 50-figure human set
  and the four-model comparison (Gemma 4 26B-A4B / 31B, Qwen 3.6 35B-A3B / 27B).
